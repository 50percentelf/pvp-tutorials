# PvP Tutorials

A private RuneLite plugin that extends Pete Kayer's PvP tutorial system with additional client-side combat training scenarios.

## Goal

Add custom PvP tutorials that fill gaps between Jagex's existing lessons. All tutorial logic runs entirely client-side — no server actions are fabricated.

## Running

```
./gradlew run
```

Then log in using [Jagex Account instructions](https://github.com/runelite/runelite/wiki/Using-Jagex-Accounts).

Phase 1 — Pete Kayer widget/arena discovery in progress.
